# DriveWise v16

Admin CMS editing upgrade.

The Admin content area now allows full management of existing content:
- Edit any published blog
- Edit any news article
- Edit any buying guide
- Edit any modification guide
- Edit any comparison
- Edit any Monthly DriveWise edition
- Change title, category, date and excerpt
- Edit rich HTML content including H2/H3 headings, lists, quotes, bold/italic and links
- Edit SEO title and meta description
- Re-run the content SEO checker after editing
- Save changes without creating a duplicate article
- Make any article the featured Monthly DriveWise edition
- Unfeature the current Monthly edition
- Delete articles

Existing Admin login, analytics, site SEO audit, My Garage, Guides, Mod Library, shortlist and parts comparison are retained.
